# id: REL-p5-03-theft-owned-seen
# covers: SR13 (a conscious owner sees the theft: the game's own HUNT_MY_THIEF = caught), SR14 (one item = petty;
#   handing it back = a small compensation, never a theft by the owner)
# fixture: auto-home
# reset: fresh
# needs: Stobe with pending-fixes/rel_theft_caught_native.py; server cb3bc44 + 2fbd947; harness e8b4688+ (drop ... owned) and a68f72d+ (KAH 23 crime ... commit);
#   StobeCustom.ini [SocialRelationships] Capture=1; mode shadow
# verify: php tools/social_relationship_inspect.php --pair-effects --interpret-log 40 --log-filter "Rel Tess" --check-shadow -> exit 0
#   pair_effects: "<TNAME>" -> "Shay" petty_theft in [-8,-3] (shadow, not applied) and property_returned (+3..+9);
#   NO row "Shay" -> "<TNAME>" (the hand-back is no theft by him). Interpret log: stolen_gain + theft_caught (either order).
#   No "theft hunt" line = the game raised no alarm: report the pickup reply (item_stolen=, crime report) and the crime step.
@wait-world
@sleep 8
speed 0
@set SHAY where Shay ~ Shay (#\d+/\d+)
@set SHAY_S where ${SHAY} ~ (#\d+)/\d+
protect Shay on
teleport Malzin Shay dist 60
# m22: Nomads, not Drifters: Drifters is "not a real faction" (FCS), BountyManager::setCrime refuses it and the game
# never treats taking their goods as a crime (no HUNT_MY_THIEF, crime commit set=0)
spawn "Hungry Bandit" Nomads near Shay dist 10 count 1 ~ spawned 1/1
@set O chars 40 ~ Hungry Bandit\]? (#\d+/\d+)
@set O_S where ${O} ~ (#\d+)/\d+
# run m11: Malzin/Shay attack the test faction otherwise
relation ${O} 60
setname ${O} "Rel Tess" ~ ^([^ ].* \[)?Hungry Bandit\]? ->
@set TNAME where ${O} ~ ^(.+?) #\d+
give ${O} "Iron Plates" 1 ~ got 1/1
# the world sweep only watches NPCs it has met (run m8)
stobe_say "Rel Tess" "Tess, wait here a moment."
speed 1
@sleep 10
speed 0
# M23_F8_REL: end the greeting's FOLLOW_WHILE_TALKING so her own theft reaction can run
order ${O} IDLE
teleport ${O} Shay dist 4
drop ${O} "Iron Plates" owned ~ owner_faction=Nomads
# m22: let the owner's pending loss expire (6 s) so the pickup is an item_gain, not an in-sweep transfer from him
@sleep 8
stealth Shay off
crime Shay ~ committing_crime=
# the PICKUP order only runs while the game runs; the reply comes when the plate is in Shay's inventory
speed 1
pickup Shay "Iron Plates" near ${O} radius 15 ~ picked up .*item_stolen=
@sleep 15
speed 0
crime Shay ~ hunters=
# m22: the game's sight check raised no alarm (hunters=0, Tess 4 m away): raise the game's own crime state
# against her faction (harness KAH 23); her own AI must start HUNT_MY_THIEF, which Stobe logs as "theft hunt".
crime Shay commit stealing against ${O} witnessed ~ set=1
speed 1
@sleep 10
speed 0
crime Shay ~ hunters=[1-9]
@log D:\Steam\steamapps\common\Kenshi\RE_Kenshi\mods\Stobe\stobe.log ~ SOCIAL_CAPTURE: structured kind=item_gain seq=\d+ load=\d+ actor=${SHAY_S} target=#0 witnesses=\d+ facts="items":\{[^}]*\},"stolen_items":\{"[^"]+":1\}
@log D:\Steam\steamapps\common\Kenshi\RE_Kenshi\mods\Stobe\stobe.log ~ SOCIAL_CAPTURE: theft (hunt hunter|dialog ev)=.* thief=Shay
@log D:\Steam\steamapps\common\Kenshi\RE_Kenshi\mods\Stobe\stobe.log ~ SOCIAL_CAPTURE: structured kind=theft_caught seq=\d+ load=\d+ actor=${SHAY_S} target=${O_S}
# SR14: Shay hands it back
speed 1
@sleep 3
speed 0
transfer Shay ${O} "Iron Plates"
speed 1
@sleep 10
speed 0
@log D:\Steam\steamapps\common\Kenshi\RE_Kenshi\mods\Stobe\stobe.log ~ SOCIAL_CAPTURE: structured kind=item_transfer seq=\d+ load=\d+ actor=${O_S} target=${SHAY_S}
protect Shay off
